# `docs` — System Documentation Source

> **Subsystem Role:** Technical Documentation & Architecture Reference Source

The `docs` directory contains Markdown source files used to build the official ClauseOS site and developer guides via MkDocs.

---

## Directory Function

* **Architecture Specifications:** Deep dives into profile confinement, the single-driver model, and OS primitive mappings.
* **CLI Command Reference:** Complete documentation for `clause pkg`, `clause cloud`, and `just` targets.
* **Deployment Guides:** Step-by-step guides for seed node initialization, Pulumi cloud bursting, and cluster detachment.

---

## Key Files

* `index.md`: Main portal page for documentation.
* `architecture/`: OS primitive mappings and kernel design notes.
* `guides/`: Quick start and operational execution guides.
