# `site` — Generated Documentation & Public Artifacts

> **Subsystem Role:** Generated Documentation Build Output Target

The `site` directory contains compiled static HTML documentation, build artifacts, and published assets generated by MkDocs or system static site generators.

---

## Directory Function

* **Build Output Target:** Serves as the transient destination for compiled site documentation generated from `docs/` via `mkdocs build`.
* **Static Hosting Ready:** Contains standalone assets suitable for previewing locally or publishing directly to GitHub Pages / cloud hosting.

---

## Usage

```bash
# Build documentation into the /clause/site directory
just docs-build
```
