# `projects` — Isolated Development Workspace

> **Subsystem Role:** Confined User Workspace Root

The `projects` directory is the default location for user projects, code repositories, and scratchpads developed inside the ClauseOS profile.

---

## Directory Function

* **Workspace Isolation:** Ensures all code, git clones, and build artifacts generated during daily work remain fully contained inside `/clause/projects`.
* **IDE Root Target:** Serves as the primary workspace folder when launching Portable VS Code from ClauseOS.
