# `resources` — Static Assets & Media Artifacts

> **Subsystem Role:** Immutable System Assets & Media Storage

The `resources` directory stores static media, branding assets, architecture diagrams, and default profile templates used throughout ClauseOS.

---

## Directory Function

* **Branding & Logos:** Houses vector graphics, badges, and project icons used in documentation and web pages.
* **Architecture Diagrams:** Contains source images and visual models documenting the microkernel/userland mapping and cloud-bursting lifecycle.
* **Templates & Boilerplates:** Holds seed configurations and static templates for system bootstrap.
