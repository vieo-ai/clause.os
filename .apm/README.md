# `.apm` — Agent Package Manager Metadata

> **Subsystem Role:** AI Agent & Workflow Package Manifests

The `.apm` directory stores package definitions, agent prompts, and task instructions for AI-driven development workflows and automation tools operating inside ClauseOS.

---

## Directory Function

* **Agent Package Definitions:** Complements `apm.yml` by storing agent capability manifests and task definitions.
* **Autonomous Workflows:** Defines execution scopes and context boundaries for AI agents interacting with the ClauseOS command plane.

---

## Related Files

* `apm.yml`: Top-level Agent Package Manager declaration file sitting at workspace root.
